# 🚀 Tenspick Client Portal — "From Spark to Scale"

A premium, comprehensive **Client Portal & Project Delivery Platform** built for **Tenspick** (All-in-one Creative & Tech Partner). Designed to centralize project tracking, deliverables review, digital sign-offs, structured feedback cycles, communication, invoicing, and post-delivery support.

---

## 🌟 Key Capabilities & Portal Features

### 1. 👥 Multi-Role Support & Persona Switcher
- **Client (Main User):** Sarah Jenkins (CEO @ Acme Technologies) — full access to projects, deliverables sign-offs, invoices, and feedback.
- **Client Team Member:** David Chen (Head of Product Marketing) — view and comment access, with approval permissions restricted.
- **Tenspick Project Manager:** Alex Rivera — milestones management, deliverable uploads, weekly sprint reports, and ticket resolution.
- **Tenspick Team Specialists:** Elena Rostova (Lead Dev & UI/UX Designer) — assigned tasks and deliverables.
- **Agency Super Admin:** Full operational metrics, feedback inbox, testimonial publisher, and standard service checklist templates.

### 2. 📊 Executive Dashboard
- **Action Required Box:** Immediate alerts for items awaiting client action (deliverable approvals, milestone payments, content/credentials).
- **Process Roadmap:** Visual tracking across *Discover and Define*, *Design and Build*, and *Launch and Grow*.
- **Assigned Contact Card:** Direct WhatsApp quick button (`+91 98765 43210`) and video sync booking.
- **Live Progress & Latest Deliverables:** Animated milestone progress bar and preview cards.

### 3. 📦 Deliverables Hub & In-Image Pin Annotations
- **Deliverables by Service Checklist:** Standard checklists for all 6 core services:
  1. *Web Development & E-commerce*
  2. *Mobile / Application Development & SaaS*
  3. *CRM, POS & Custom Software*
  4. *AI Automation*
  5. *Creative & Branding (Logo, Video, Thumbnails)*
  6. *Digital Marketing*
- **Interactive Live Preview Canvas:** Test prototypes, staging websites, and builds.
- **Visual Pin-a-Comment Tool:** Click anywhere on the image canvas to leave pinpoint feedback.
- **Legally Recorded Digital Sign-Off:** Records approver's name, timestamp, and unique hash for dispute protection.
- **Structured Change Request Tickets:** Specify change type (*Design, Content, Functionality, Bug*), priority, and attachments.

### 4. 💬 3-Tier Feedback Architecture
- **Deliverable Change Requests:** Auto-generated ticket IDs (`#CR-xxx`) with live status tracking (*Received, In Progress, Done*).
- **1-Minute Milestone Check-ins:** Quick pulse checks measuring satisfaction, communication clarity, and timeline health.
- **Comprehensive Final Project Feedback (NPS):** 8-criterion performance ratings, Net Promoter Score (0-10), open-ended questions, and testimonial permissions.
- **Automated Alerts:** Dispatches personal outreach alert if any rating is 3 stars or below.
- **Portal Feedback:** Built-in *"Report a problem / Suggest an improvement"* channel.

### 5. 🗄️ Integrated Operations Modules
- **Messages & Weekly Updates:** Real-time project chat thread with simulated email and WhatsApp alerts.
- **Files & Documents Vault:** Categorized AES-256 cloud repository with expiring download tokens.
- **Invoices & Payments:** Itemized GST breakdown (18%), instant settlement (UPI QR Code, Bank Transfer NEFT, Credit Card), and printable tax invoices.
- **Support & Post-Launch Warranty:** 24-hr SLA countdown tracker and complimentary 90-day warranty monitor.
- **Meetings Scheduler:** Book strategy calls or demos with Google Meet calendar links and past recording archives.
- **Policy & Legal Center:** Complete human-readable agreements (Revision Policy, Handover, IP Rights transfer, AMC Retainers).
- **Agency Admin Panel:** Real-time KPI metrics, central feedback inbox, and 1-click testimonial publishing to `tenspick.com`.

## 🛠️ Tech Stack

- **Framework:** React 19 + Vite 8
- **Styling:** Tailwind CSS v4 (Glassmorphic Dark Theme with Tenspick Purple `#6C4CC4`)
- **Icons:** Lucide React
- **Animations & Effects:** Canvas Confetti & Framer-style micro-interactions
- **Typography:** Plus Jakarta Sans & JetBrains Mono

## ⚡ Getting Started Locally

```bash
# 1. Clone the repository
git clone https://github.com/hemadrikaligiri4-source/tenspick.git

# 2. Navigate to project folder
cd tenspick

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.
